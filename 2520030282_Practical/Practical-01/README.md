Linux System Resources & Services:
Linux is responsible for managing hardware resources and offering services that make it easier for users and applications to interact with the system. Below are some useful commands and concepts.
Key Commands:
uname -a  
Displays system information including kernel version, OS name, and architecture. Helpful for verifying environment details.
lscpu  
Summarizes CPU specifications such as model, number of cores, threads, and architecture.
lsblk  
Lists block devices (disks, partitions) and shows how storage is structured and mounted.
ps  
Provides a snapshot of active processes along with their process IDs (PIDs).
top  
Offers a real-time view of running processes, CPU load, and memory usage.
